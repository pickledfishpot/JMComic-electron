# v0.1.0（2026-09-04）

首个打包发布版本（Windows zip）。

## ✨ 新增（Phase 0-6 全量）

- 浏览：首页推荐 / 最新更新 / 每周必看 / 搜索 / 分类
- 书籍详情 + 评论；阅读器（JM 图片反分割、翻页/滚动双模式、快捷键、进度恢复）
- 用户体系：登录 / 注册 / 验证码，cookie 会话持久化；收藏夹管理
- 下载队列：每章一任务、4 并发拉页、断点续传、暂停/重试/删除
- 本地图库：目录本/zip 扫描、离线阅读复用阅读器
- 工具：Waifu2x 超分（sr_vulkan 懒加载探测，不可用隐藏）、代理设置与连通性测试、DNS 工具
- 原生外壳：单实例锁、系统托盘（关闭到托盘）、窗口状态持久化
- Clay 设计系统前端样式

## 🔧 构建与 CI

- PyInstaller onedir 打包后端为 extraResources；electron-builder 出安装包（当前仅 Windows zip）
- GitHub Actions 打 tag 自动构建并发草稿 Release
- 后端启动诊断：spawn 错误/崩溃输出进 splash 与 `backend-stdout.log`，CI 冒烟测试冻结尾
